# Sample resumes

Four synthetic resumes for demoing. No real people: every name, email and phone number is made
up, and every domain is `example.com`.

Upload them through the Candidates screen to populate the database. They are deliberately
different from each other -- Python/Django, Java/Spring, data engineering, full stack -- so
matching has something to get right and something to get wrong.

Generated by `prototype/make_sample_resumes.py`.
