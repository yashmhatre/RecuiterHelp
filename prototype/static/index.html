One-time Google Cloud setup (about 10 minutes)
  1. Open Google Cloud Console and create a project.
  2. APIs & Services → Library, search Gmail API, click Enable.
  3. OAuth consent screen → External → fill in the name and your email → add yourself as a Test user. Missing this step is the usual cause of "access blocked".
  4. Credentials → Create credentials → OAuth client ID → Desktop app, then Download JSON.
  5. Upload that file below.

A personal gmail.com account in Testing mode has its login revoked by Google every 7 days, so expect to reconnect weekly. A Workspace account with an Internal app does not.

Fetch

Reads recent messages and runs the two free stages on each — pre-filter and sender verification — so you can see which would even reach a model before spending a call.

Labelling queue

Pull real mail into the labelling queue. This is the blocking task for every accuracy number — 200 to 300 labelled emails. Bulk mail is skipped unless you include it, but the set needs at least 25% non-recruiter, so include it once you have enough recruiter mail.

Mailbox

Click Classify to run one message through the full pipeline. Save draft in Gmail writes a real draft into the thread and labels it “AI Draft”. Nothing is ever sent.
